# Poli-REDI — Evidencias de pruebas

Este directorio contiene los casos de prueba, scripts y evidencias
generadas durante la validación de Poli-REDI.

El roadmap general se encuentra en:

`docs/testing/ROADMAP-PRUEBAS.md`

## Organización

- `00-plan`: planificación y configuración de pruebas.
- `01-mvp1`: pruebas funcionales del MVP 1.
- `02-mvp2`: pruebas funcionales del MVP 2.
- `03-mvp3`: pruebas funcionales del MVP 3.
- `04-mvp4`: pruebas funcionales del MVP 4.
- `05-performance`: pruebas de rendimiento, carga y estrés.
- `06-security`: pruebas de seguridad.
- `07-regression`: pruebas de regresión.
- `08-final-report`: informe final de validación.

Las evidencias deben identificar el caso de prueba, fecha,
versión del sistema y resultado obtenido.

No almacenar tokens, contraseñas ni secretos.
